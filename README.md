# Image Denoising using SwinIR

Applied the SwinIR vision transformer architecture to image denoising and restoration tasks.

## What it does
- Removes noise from images using a Swin Transformer-based model
- Built end-to-end in Jupyter with custom image preprocessing
- Tested on standard image benchmarks

## Tech Stack
- Python · PyTorch · SwinIR · OpenCV · Jupyter Notebook

## How to Run
1. Open `SwinIR_Denoising.ipynb` in Jupyter or Google Colab
2. Run `img_download.ipynb` first to download sample images
3. Run all cells in order
